本仓库包含两个围绕 CS2 饰品市场的独立项目，分别聚焦不同层面的问题：

| 项目 | 目录 | 定位 | 核心能力 |
|---|---|---|---|
| **① 量化分析系统** | 根目录 | 面向**个人交易者**：把行情变成可执行的信号 | 规则引擎信号检测 · 技术指标 · AI 每日早报 · Web 看板 |
| **② 全市场数据系统** | [`steamdt-market-ai/`](steamdt-market-ai/) | 面向**数据基础设施**：把全市场数据变得可查询 | 全市场采集（8969 款）· MySQL 建模 · 中英文智能搜索 |

两个项目共用 SteamDT 作为数据源，但技术栈与解决的问题互补：
- 项目① 用 **CSV + 固定规则** 输出**结论**
- 项目② 用 **MySQL + 语义检索** 支撑**查询**

# 项目①：CS2 饰品量化分析系统

> 一个接入**真实市场数据**、由 **AI 自动生成每日市场早报**的 CS2 饰品（皮肤）量化分析平台。

## 项目背景

CS2 饰品市场是一个规模可观、流动性良好的二级交易市场，价格受赛事、版本更新、资金轮动影响波动明显。但普通玩家面临三个问题：

1. **数据分散**：价格、挂单量、求购量散落在 BUFF、悠悠有品、Steam 等多个平台
2. **看不懂信号**：缺乏技术分析能力，不知道什么时候该关注、什么时候该规避
3. **信息过载**：十几款皮肤的价格变化，人工盯盘成本高

本项目通过「**规则引擎算信号 + 大模型做解读**」的分工，把原始行情数据转化为可读的市场判断。

## 核心功能

| 模块 | 说明 |
|---|---|
| 📡 **真实数据采集** | 对接 SteamDT 开放平台，拉取 365 天真实日 K 线 + 各平台挂单量/求购量 |
| ⚡ **信号 A：吸筹埋伏** | 窄幅横盘 + 供给偏紧（挂单量低于市场中位数）+ 趋势完好 |
| 🔵 **信号 D：板块补涨** | 同板块已涨但本款滞涨，捕捉板块轮动补涨机会 |
| 📊 **挂单量排行** | 稀缺度 / 流动性 / 在售总市值三维度分析 |
| 🗺️ **板块热力图** | 各武器系列近 30 日表现对比 |
| 🚨 **异动监控** | 价格、成交量、挂单量的异常波动告警 |
| 🤖 **AI 智能解读** | 针对单款皮肤或全市场，由大模型生成自然语言解读 |
| 📰 **AI 市场早报** | 一键生成结构化每日早报（7 大板块） |

## 设计思路

### 1. 规则引擎与 AI 的分工

```
原始行情数据
    ↓  pandas 计算技术指标（MA / 布林带 / RSI / MACD）
    ↓  规则引擎产出可解释、可复现的交易信号
    ↓  把信号 + 挂单量 + 板块表现组织成上下文
    ↓  大模型负责"翻译"与"归纳"，生成人类可读的报告
```

**为什么不让 AI 直接分析原始数据？**

- 规则引擎的输出**可解释、可复现、参数可调**，是判断的骨架
- 大模型擅长的是把结构化结论转成自然语言，而非从原始数据中发现规律
- 数据里没有的内容，Prompt 明确要求 AI **不得编造**（实测有效）

### 2. 用「挂单量」替代「成交量」

SteamDT 不提供历史成交量，但这反而促成了一个更优的设计：

- **挂单量骤降 = 有人扫货**（吸筹最直接的证据）
- **挂单量偏低 = 供给稀缺**（价格更容易被拉升）

相比成交量，挂单量反映的是**供给端**的变化，对判断吸筹更直接。

信号 A 的流动性判断分两级降级：
1. 有挂单量历史 → 检测「骤降」（扫货）
2. 仅有当日快照 → 检测「是否低于市场中位数」（稀缺）
3. 无数据 → 该条件不计分，并在信号中明确标注「流动性未验证」

## 技术栈

- **后端**：Python 3.12 + Flask
- **数据处理**：pandas / numpy
- **前端**：原生 HTML/JS + Plotly 图表
- **存储**：CSV（轻量，便于查看与迁移）
- **AI**：DeepSeek API（OpenAI 兼容，可切换智谱 / 通义）
- **数据源**：[SteamDT 开放平台](https://doc.steamdt.com/)

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密钥（二选一）
#    方式 A：环境变量（推荐）
set AI_API_KEY=sk-你的DeepSeek密钥
set STEAMDT_API_KEY=你的SteamDT密钥

#    方式 B：填在 config/settings.py 的 AI_CONFIG / STEAMDT_CONFIG 中

# 3. 启动
python main.py
```

浏览器访问 `http://127.0.0.1:5000`


## 数据说明

- **价格**：来自 SteamDT 单品 K 线接口，365 天真实日 K 数据
- **挂单量 / 求购量**：来自 SteamDT 各平台价格接口，每日采集一次逐步积累历史
- **覆盖**：市面上全部主流皮肤的 Field-Tested / Factory New 品相
